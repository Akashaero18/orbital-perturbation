# Orbital Perturbation Analysis

Compares SGP4 (analytical with perturbations) vs. Keplerian (ideal ellipse) propagation models over 7 days 
for three satellites at different altitudes.

## Key Result
LEO satellites (ISS, Hubble) drift thousands of kilometers from Keplerian predictions due to atmospheric 
drag and J₂ oblateness. GEO satellites remain stable, showing perturbations are altitude-dependent.
Outputs a logarithmic plot comparing drift for ISS, Hubble, and GOES-19 over 7 days.
